# ResumeCraft

ResumeCraft is a privacy-first resume builder that works in the browser. Create a resume from scratch or import an existing PDF or DOCX, refine the content, customize the presentation, and export a polished PDF—without creating an account.

[Try ResumeCraft](https://resumecraft.netlify.app/)

## What it offers

- Three recruiter-friendly templates with live preview
- Flexible sections, typography, spacing, colors, and page controls
- Local draft saving, JSON backups, and browser-based resume import
- Actionable Resume Health feedback without a misleading ATS score
- Selectable, link-aware PDF export with page-overflow warnings

Resume data stays in the browser. Information is sent externally only when a user explicitly submits the optional feedback form.

## Contribute

ResumeCraft welcomes bug reports, product ideas, design improvements, documentation, and code contributions.

- [Create an issue](https://github.com/snehil21/ResumeCraft/issues/new) to report a problem or propose an improvement.
- Browse the [open issues](https://github.com/snehil21/ResumeCraft/issues) and submit a focused pull request for one you would like to help with.
- In your pull request, link the issue, explain the change, and describe how you verified it.

Thoughtful issues and pull requests are welcome, including from first-time contributors.
